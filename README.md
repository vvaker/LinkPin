# 链接直达（LinkPin）

Android 本地小工具：收藏视频、书籍或网页链接，点击列表卡片直达内容；需要桌面入口时，再把链接固定为桌面快捷方式。在 B 站等 App 里分享链接时，也能直接保存进列表。点击快捷方式时按域名直达目标 App 或默认浏览器，同一域名只问一次"用哪个打开"。

- 应用 ID：`com.local.linkpin`
- 平台：Android 7.1（API 25）及以上
- 特性：系统分享保存（分享链接即入列表，重复链接自动更新）、`b23.tv` 短链自动展开（失败回退原链接）、列表点击直达、桌面快捷方式按需生成、自定义名称与相册图标（选图后可拖动/缩放裁剪、点击预览）、默认字母图标、首次路由选择（可勾选“记住”）与域名记忆、完整编辑/删除

## 构建

前置条件：JDK 17、Android SDK 35（`local.properties` 中配置 `sdk.dir`）。首次构建需要联网下载依赖，Gradle wrapper 使用腾讯镜像。

```cmd
gradlew.bat testDebugUnitTest assembleDebug
```

产物：`app\build\outputs\apk\debug\app-debug.apk`（debug 签名，可直接侧载）

## 安装

```cmd
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

安装后权限说明：

- `QUERY_ALL_PACKAGES`：查询能处理目标链接的已安装应用（自用 MVP 采用；上商店前需改为定向 `<queries>`）。
- `com.android.launcher.permission.INSTALL_SHORTCUT`：旧版桌面快捷方式降级广播。
- `INTERNET`：只在接收分享、需要展开 `b23.tv` 短链时发起一次请求；展开失败会回退保存原始链接，其他功能不需要网络。

## 使用

1. 在哔哩哔哩等 App 里打开视频页，点「分享」。注意 B 站页面里弹出的分享面板是 B 站自己画的，里面不会出现「链接直达」；需要点该面板里的「更多」（通常是最后一个图标，部分版本叫「系统分享」），在随后的 Android 系统分享面板里选「链接直达」。弹出保存卡片后，名称一般已从分享文本的【标题】自动填好，可修改；点「保存」直接进列表，不会自动生成桌面图标。若列表里已有同一视频（含不同追踪参数或等价的 `b23.tv` 链接），会提示并更新原记录。如果分享面板里找不到「更多」，可以先点「复制链接」，再打开应用点右下角 + 粘贴保存。
2. 也可以打开应用，点右下角 +，粘贴链接（如 `https://www.bilibili.com/video/BV1xx`）、填写名称，可选相册图片作为图标（选图后可拖动/缩放裁剪）。
3. 保存后回到列表。点击卡片即可直达链接内容：首次打开同一域名会出现一次"选择打开方式"面板；勾选"记住我的选择"后同域名其他链接直接打开、不再询问，不勾选则下次继续询问。
4. 需要桌面入口时，点击卡片尾部的图钉按钮，在系统提示中确认，即可在桌面生成快捷方式；桌面快捷方式与应用内点击走同一条路由。
5. 卡片尾部还支持编辑与删除；删除只移除应用内记录，桌面上的旧图标需长按移除。

## 已知限制

- 桌面已固定的旧图标无法由应用自动删除（系统限制）；应用会尽力清理旧版广播安装的图标，点击已删除的图标会弹出「快捷方式已失效」对话框，点「确定」尝试移除，若图标仍在可长按桌面图标手动移除。
- 分享入口的位置由来源 App 决定：B 站把系统分享藏在「更多」里时，需要多点一步；分享文本里没有标题时，会用链接或域名推断一个名称。
- 短链（`b23.tv`、`v.douyin.com` 等）可能先经浏览器跳转一次；接收分享时会尝试展开 `b23.tv`，无网络或展开失败时回退保存原始短链。
- 微信读书的分享链接是带分享 token 的网页地址（`/book-detail?v=...`）：token 要在网页端换成 `bookId` 才能定位到书，直接交给微信读书 App 只会落到主页。因此这类链接固定走默认浏览器，由网页再唤起 App 到具体书。
- 部分国产桌面对快捷方式固定支持不一致：不支持时会尝试旧版 INSTALL_SHORTCUT 广播，仍失败请点击列表里的图钉按钮重试。
- 数据仅存本机；卸载应用会清除所有记录、规则与图标文件。
